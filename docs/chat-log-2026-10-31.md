### What the n8n workflow does
1. **Log form** (`/form/lead-activity-log`): entry types New Lead, Call, Appointment Set,
   Presentation Held, No-Show, Application Submitted, Policy Issued, Follow-Up.
   Writes a Tracker row, then finds or creates the HubSpot contact (by email, else by
   phone) and **adds a note** to it. The contact's message field is no longer overwritten.
2. **Calendly booking**: writes an "Appointment Set" Tracker row and adds an
   "Appointment booked" note to the HubSpot contact.
3. **Kixie calls** (End Call + PowerDial Attempts webhooks): reads the Power Lists tab,
   writes a Tracker row tagged with the power list. Lists with Category "Recruiting" are
   logged as Type `Recruiting Call`; everything else is `Call`. Notes start with
   `Connected` or `No answer`. A power list ID not yet in the Power Lists tab is added
   there automatically so you can name it.
4. **8 AM report** (Regina time): emails ALP progress against $20k to Gmail.
